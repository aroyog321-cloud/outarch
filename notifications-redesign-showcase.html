React Component API & Implementation

Drop-in compatible with existing useToast() and NotificationTray.jsx hooks in Mission Control: 

// 1. Port Conflict with 1-Click Kill Action
toast.danger("Port 3000 is occupied by PID 9184 (node)", {
  title: "Port 3000 Collision",
  source: "web-client",
  actions: [
    { label: "⚡ Kill PID 9184 & Start", run: () => killAndStart(9184, 3000), tone: "danger" },
    { label: "Use Port 3001", run: () => startOnPort(3001) }
  ]
});

// 2. Live Background Task with in-place transition
const task = toast.progress("Building Docker Image...", { source: "build-srv" });
task.updateProgress(0.68, "Step 4/6: Compiling rust crates");
// On completion:
task.succeed("Docker Image 'prod-worker:v2.1' ready", { 
  actions: [{ label: "Deploy to Cluster", run: () => deploy() }] 
});

// 3. AI Copilot Insight
toast.ai("Unclosed Redis pool detected in callback.ts:48", {
  title: "Mission AI Memory Anomaly",
  actions: [
    { label: "✨ Apply Auto-Patch", run: () => applyPatch(), tone: "ai" },
    { label: "Explain in Chat", run: () => openAiAssistant() }
  ]
});
