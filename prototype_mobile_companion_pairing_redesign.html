Native Mobile Input & Revocation Lifecycle Specs

1. Native Mobile Numeric Keyboard (Zero Screen Clutter)

Removed artificial on-screen keypad. The 6-slot container is wired to a native inputmode="numeric" and autocomplete="one-time-code" field. On smartphones (iOS/Android), tapping any slot opens the device's native numeric pad and auto-fills codes from clipboard.

2. Instant Re-Pairing on Revocation (Bug Fix)

When a desktop operator revokes a mobile device, any failed request or SSE event immediately triggers localStorage.removeItem(). The phone client automatically resets to the 6-digit PIN screen rather than remaining trapped in a broken state.

3. Synchronous Device Removal from Integrations Tab (Bug Fix)

When mobile.device.revoke is triggered on the desktop, local React state is updated synchronously via setDevices(prev => prev.filter(d => d.id !== id)) so the revoked device disappears immediately from the table without requiring a restart.
